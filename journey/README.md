# Лабораторные по алгоритмическому маркетингу

Текущая версия использует один общий кейс продуктового магазина для восьми работ. Для анализа тональности используется отдельный набор отзывов Amazon.

- [The Complete Journey на Kaggle](https://www.kaggle.com/datasets/frtgnn/dunnhumby-the-complete-journey), версия 1. Это двухлетний выпуск с 2 500 домохозяйствами и 2 595 732 строками покупок. Он отличается от однолетнего пакета completejourney с 2 469 семьями.
- [Multi-Domain Sentiment Dataset](https://www.cs.jhu.edu/~mdredze/datasets/sentiment/). Использован исходный четырёхдоменный выпуск 2007 года, доступный через ссылку `still available here`. В работе 5 анализируются исходные тексты категории electronics.

В Python for Data Science прямо назван Multi-Domain Sentiment Dataset и есть ссылка на каталог Kaggle Datasets. Complete Journey выбран внутри этого каталога. Прямое упоминание Complete Journey в учебнике не заявляется.

## Подготовка данных и запуск

Все команды выполняются из этой папки. В репозитории это `journey`, в архиве материалов это корневая папка.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows окружение активируется через `.venv\Scripts\activate`.

Скачайте ZIP версии 1 Complete Journey с указанной страницы Kaggle. Для загрузки через сайт может потребоваться вход. Затем подготовьте семь используемых CSV и скачайте отзывы из официального источника.

```bash
python code/prepare_data.py --archive /path/to/archive.zip
python code/download_sentiment.py
python code/run_all.py
python code/make_charts.py
```

В локальном архиве материалов использованные CSV и архив отзывов уже лежат в `data`, поэтому подготовку можно пропустить. Таблица `causal_data.csv` есть в ZIP Kaggle, но не используется: рекламная работа посвящена адресным купонам и отклику, а не выкладке товаров.

Результаты сохраняются в `results`, графики Matplotlib в `figures`. Скрипт `profile_data.py` создаёт таблицы описательной статистики, 19 мини-гистограмм и диаграмму корреляции. Он запускается последним в `run_all.py`. Профили содержат все 12 полей покупок и семь используемых полей отзывов, типы, пропуски, уникальные значения, медианы и полные диапазоны. Этапы очистки сверяются с итогом лабораторных; точные показатели находятся в `results/data_profiles.json`. Хеши исходных файлов находятся в `sources.json`. Запуск рекомендаций для произвольного кода семьи:

```bash
python code/lab02.py --household 1
```

HTML-демонстрация переключает заранее рассчитанные примеры реальных семей. Для нового кода семьи запускается Python.

## Генерация рекламных текстов

Для работы 9 дополнительно нужны Node.js 22+ и npm.

```bash
npm install
python code/lab09.py
```

Скрипт запускает Qwen2.5-1.5B-Instruct локально через Transformers.js на CPU. При первом запуске загружаются веса ONNX q4, примерно 1,7 ГБ. Ключ API и платная подписка не нужны. Переменная `MARKETING_NODE` позволяет задать путь к Node.js, `MARKETING_MODEL_CACHE` задаёт папку кэша.

`run_all.py` без флага только готовит входы генератора. Полный запуск всех работ с генерацией:

```bash
python code/run_all.py --generate
```

Исходные запросы и реальные английские ответы находятся в `lab09_generation.json`, отдельно отредактированный русский перевод в `lab09_reviewed.json`. На слайдах показан перевод после правки, а не дословный русский вывод модели. В выполненном запуске создано пять черновиков, четыре прошли строгие автоматические проверки. Один потребовал исправления категории и удаления неподтверждённых описаний.

## Как читать результаты

Время Complete Journey представлено номерами дней и недель. Календарные даты не назначались. Клиентом считается домохозяйство, а не подтверждённый отдельный человек. Полные повторы строк покупок отсутствуют. После исключения нулевого количества и неположительной оплаты осталось 2 574 087 строк и 275 518 корзин.

`SALES_VALUE` отражает поступление магазину. Фактическая оплата покупателя вычисляется как `SALES_VALUE + COUPON_DISC`, поскольку скидка производителя записана отрицательным числом. Скидка магазина и его доплата к купону уже учтены в `SALES_VALUE` и повторно не вычитаются. Валюта — доллары.

Рекомендации по связям товаров дали попадание 24,9%, общий популярный список 31,6%. Для цены молока ошибка сложной модели составила 0,19 доллара, перенос прошлой цены дал 0,13. Эти результаты честно отражены в выводах. При прогнозировании популярности модель почти не улучшила перенос охвата прошлого периода, 9,41 против 9,42 семьи средней ошибки.

Отклик на кампанию означает хотя бы одно погашение купона семьёй в сроки кампании. Семья могла участвовать в нескольких кампаниях. Наблюдаемое отличие персональных купонов от общих не является доказанным эффектом персонализации. Предел стоимости контакта рассчитан при одинаковой ценности отклика; фактические рекламные расходы и оптимальный бюджет без них не выдумываются.

Отзывы Amazon намеренно сбалансированы авторами набора. Доля негативных текстов не оценивает долю недовольных покупателей Amazon. Тональность размечена по звёздам, проверочные товары отделены от обучающих. Темы означают упоминания ключевых слов и могут пересекаться; перед изменением сервиса нужна ручная проверка примеров.

RFM рассчитан по последнему году на день 712. Его группа «Неактивные» определена относительными баллами и отличается от метки отсутствия покупок 60 дней. В работе 10 эта метка проверяется по более позднему полностью наблюдаемому окну. Порог модели выбран на отдельном валидационном периоде. Предложенные меры удержания ещё требуют эксперимента.

В публичный репозиторий попадают только код, зависимости, инструкция, источники и карта задания. Датасеты, исходный PDF, презентация и веса модели не публикуются.

При использовании отзывов указывайте публикацию авторов набора. John Blitzer, Mark Dredze, Fernando Pereira. *Biographies, Bollywood, Boom-boxes and Blenders: Domain Adaptation for Sentiment Classification*. ACL 2007.
