# Лабораторные на общем кейсе Olist

Эта версия пересчитана на данных одного бизнеса. Используются два связанных публичных выпуска Olist, а не четыре несвязанных учебных компании.

- [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) содержит покупки, цены, товары, покупателей, продавцов, тексты и оценки отзывов.
- [Marketing Funnel by Olist](https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist) содержит источники заявок и подключения продавцов. Он связан с первым выпуском по seller_id.

Описание бизнеса вынесено в начало презентации. Для каждой работы остаётся её срез данных, анализ, результат и требуемые рекомендации. В первой работе есть общий аудит всех использованных таблиц. Карта соответствия пунктам задания находится в requirements_map.json. Лабораторной 3 в исходном задании нет.

## Как данные связаны с указанным в задании сайтом

В [Open data, Search engines](https://www.python4data.science/en/latest/data-processing/opendata.html#search-engines) есть ссылка [Kaggle Datasets](https://www.kaggle.com/datasets). Olist выбран внутри этого каталога. Название Olist непосредственно в учебнике не перечислено. Выбор внутри каталогов сайта отдельно согласован пользователем.

Изучены также прямо указанные Criteo Click Logs, Shopper Intent Prediction и Multi-Domain Sentiment, а также учебные файлы продаж и клиентов. Сравнение полей и пригодности работ сохранено в [dataset_selection.json](dataset_selection.json). В локальном архиве доступна читаемая версия dataset_selection.html.

Внизу слайдов первая ссылка открывает исходный раздел Python for Data Science, вторая открывает конкретный выпуск Olist. Это две разные ссылки с разным назначением.

## Запуск

Команды выполняются из папки olist в репозитории или из корня распакованного архива материалов.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python code/download_data.py
python code/run_all.py
python code/make_charts.py
```

Если CSV уже лежат в data, загрузку пропускают. В Windows окружение активируется через `.venv\Scripts\activate`. Результаты сохраняются в results, 15 графиков Matplotlib в figures. Общие функции находятся в [common.py](code/common.py). Скачанные архивы и CSV сверяются по SHA-256 из [sources.json](sources.json).

Для демонстрации рекомендаций:

```bash
python code/lab02.py --customer 05ef855308303397f1427f29470bb6ab
```

## Генерация сообщений

Для лабораторной 9 дополнительно нужны Node.js 22+ и npm.

```bash
npm install
python code/lab09.py
```

Используется публичная Qwen2.5-1.5B-Instruct через Transformers.js, CPU, ONNX q4. При первом запуске скачивается примерно 1,7 ГБ весов. Ключи и платный API не нужны. `run_all.py` только подготавливает входы генератора. Полный запуск lab09.py сохраняет реальные исходные ответы в lab09_generation.json. Русский перевод после редактуры хранится отдельно в lab09_reviewed.json и не выдаётся за дословный ответ модели. В выполненном запуске пять черновиков, два прошли все строгие проверки, в трёх потребовалась редактура.

## Что означают результаты

Рекомендации по совместным покупкам дали попадание 19,8%, список популярных категорий 44,6% на 650 вернувшихся покупателях. Поэтому сложный метод не объявлен улучшением. Модель цены также уступила простой медиане на последних днях, что отражено в решении.

Для рекламы сравнивается подключение продавца за одинаковые 60 дней. В выпуске отсутствуют затраты. При одинаковой ценности подключённого продавца сравнивается допустимая стоимость заявки относительно платного поиска. Для социальных сетей отношение равно 0,4028, для писем 0,2528. Фактическая окупаемость и оптимальное распределение денег без расходов не вычисляются. Конкретные названия рекламных платформ и креативы также не известны.

Тональность приближённо размечена по звёздам, а темы жалоб получены явными португальскими словарями. Рейтинг относится к продавцам по оценке заказа с одним продавцом. Анализ доставки описывает связь с оценкой после выполнения заказа, а не причинный эффект и не прогноз в момент покупки.

Для RFM выбран срез 1 сентября 2018. Клиенты группы риска имеют давнюю покупку и либо повторные заказы, либо крупную общую сумму. Для оттока продавцов отдельная операционная метка означает отсутствие новых заказов следующие 60 дней. Это не запись о расторжении договора. Обучение, выбор порога и проверка разделены по времени. Рекомендации по удержанию требуют отдельного эксперимента.
